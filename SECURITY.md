# Security

SafeContext is an early local-first preview. Do not submit real confidential
documents, credentials, detected values, private mappings, or restored output
in public issues.

For a security or privacy report, use the
[private contact form](https://safectx-ai-privacy.dainty-nova-4389.chatgpt.site/contact)
and describe only the affected behavior and data category. We will request a
synthetic reproduction if needed.
